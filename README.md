# Moore Lichtenau Meusebach
 Data for Master thesis

This repository contains all data about the bogs in Meusebach and Lichtenau, Thuringia, Germany, which were collected in 2025 for the master theses of Nele Herzig and Alexandra Kornhass.
The data should be used to benefit those bogs in the future.
Disclaimer: the repository holds content in english and german language

Index:
Artenlisten - contains species lists as provided by Jörn Hentschel
bachelorarbeiten lichtenau - contains previous works by other students on the site Kleiner Sumpf
Boden  - contains data and analysis concerning the soil sampling
FIS - contains data requested from the Fachinformationssystem of the Thüringer Landesamt für Umwelt, Bergbau und Naturschutz
Fotos - contains photographs that were taken during the project
GIS-Projekte - contains data that was used in any analysis and creation of figures using QGIS-SOftware
Logger - contains data and analysis files regarding the logger records and additional data such as precipitation
Nele - contains data that was mainly used by Nele Herzig for her thesis
Vegetation - contains data and analysis files regarding the vegetation of the sites
Wasser - contains data and analysis files regarding the water sampling
