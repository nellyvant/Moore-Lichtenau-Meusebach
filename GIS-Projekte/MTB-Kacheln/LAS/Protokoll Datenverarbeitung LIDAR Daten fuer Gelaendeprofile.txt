Bearbeitung
1. Laden als Punktwolke in QGIS
2. Filter nach Classification = 2 (Boden)
3. Export als .laz Benennung Kachelnummer_only_ground.laz
4. Laden der Kachelnummer_only_ground.laz in CloudCompare
	Tools -> Projection -> Rasterize
	step = 0,5
	active layer = cell height values
	direction = Z
	cell height = minimum (da es realistisch am Gelände liegt und keine künstliche Glättung oder Anhebung des Geländes mit sich bringt)
	project SF(s) deaktivieren
	fill empty cells = kriging
	Update grid
5. Export als Raster (export heights); Benennung als Kachelnummer.tiff

6. Öffnen der .tiff in QGIS
7. Öffnen von Untersuchungsflächen.shx und Logger.shx zur Orientierung
8. Profilbestimmung mit Hilfe von Add-On "Profile Tool" von einem Logger zum anderen nach Schema: W->M->O, N->M->S
9. Speichern der mittels Profile Tool erzeugten Tabelle als .csv
